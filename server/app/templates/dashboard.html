Set up a device
  1. Download kodevicesync.koplugin.zip and unzip it into your KOReader plugins/ folder (Kobo/Kindle: koreader/plugins/, Android: koreader/plugins/ on internal storage).
  2. Restart KOReader, then open Tools › KODeviceSync.
  3. Set the server to {{ server_url }} and log in as {{ user.username }}.
  4. On your main device: Choose what to sync, then Push this device's setup.
